# Job: build the twelve new Halloween pet bodies

## Why

The owner, 2026-10-19 (`wiki/open-questions.md`, "Candy Crypt v2"): **"12 more
Halloween pets, with new bodies (built in Studio)"**. The twelve pets already
exist: names, rarities, kits and serials are in
`src/ReplicatedStorage/Mine/Shared/HolidayPets/Halloween2026.luau`, generated by
`tools/gen/holiday-pets.js` from `tools/gen/holiday/halloween_2026.json`
(`extraPets`). Their bodies do not. Until a body exists, its pet wears a
stand-in: an existing Halloween body named by `fallback`, in the pet's own
colour (`PetModelFactory` does this when it merges the holiday skins). Your job
is the twelve bodies.

Five of them are the Halloween **build** pets (owner: *"make some of these pets
influence builds that wouldn't be possible without the pets, making them
exceptionally important"*), so they are the chase; give them the most presence.

## Scope

1. **One new module**, `src/ReplicatedStorage/Mine/Shared/PetBodies/HalloweenCrypt.luau`.
   The file name must start with `Halloween`: `tools/verify/set-pets.js` treats
   `PetBodies/Halloween*.luau` as holiday body modules, the only PetBodies files
   allowed a season tag. It returns `function(K)` and a table of the twelve,
   like every PetBodies module.
2. **Every body carries `season = "Halloween"`** and no `set` field. The season
   tag is what makes it a holiday body, which keeps it out of every zone pot,
   set and random roll (`PetModelFactory.HALLOWEEN` then lists it, and the pet
   display draws it in the Halloween block).
3. **Follow the body conventions** in `tools/gen/sets/README.md` §1 (the kit
   `K`, the canvas `c`, the palette `p`, `block()` and its rules) and the pet
   body notes in `wiki/systems/pets.md` ("Body shape"): features on the
   envelope, no separate head volume, FIT_SIZE (2.5 studs on the largest side,
   so set `scale` if wings or a tall prop shrink the pet), 12 to 40 parts, a
   readable face, cute and kid-friendly. **Never mesh a part as Pyramid or
   Prism** (`wiki/code/luau-traps.md` §10: Roblox draws nothing); `c:cone` is
   already built from wedges.
4. **Regenerate** with `node tools/gen/holiday-pets.js`. Each built body drops
   its `fallback` from the generated rows; nothing else in the pets changes.
   Commit the regenerated `HolidayPets/Halloween2026.luau` and
   `docs/HOLIDAY-PETS.md` with the module.

Do not edit `PetModelFactory.luau`, the JSON, the generators, names, kits or
any other pet. If a body cannot be done well, leave it out: its pet keeps its
stand-in, and the report says which.

## How to look (Studio, Edit mode only; do not start Play)

1. Load fresh code the safe way (`wiki/code/luau-traps.md` §11): clone the
   whole `ReplicatedStorage.Mine.Shared` folder somewhere private, require from
   the clone, destroy it after. Never rename a synced module aside.
2. In a Workspace folder named `_HalloweenQA`, build each body bare,
   `PetModelFactory.build({ species = "bonedragon" })`, and each pet,
   `PetModelFactory.buildFromRoster(MinePetRoster, "Boomjaw")`, in a row with
   the existing fifteen Halloween bodies (`PetModelFactory.HALLOWEEN`) beside
   them for scale and distinctness. Try a Golden and a Rainbow variant of two.
3. Capture each from the front and from a 3/4 angle. Fix floating parts, a
   hidden face, a size far off its neighbours, a clip or z-fight, or a shape
   that does not read as its label.
4. Delete `_HalloweenQA` and the private clone. Never save the place.

## Verify and finish

Run each on its own line:

```
node tools/gen/holiday-pets.js
node tools/verify/holiday-pets.js
node tools/verify/halloween-power.js
node tools/verify/set-pets.js
node tools/verify/zone-pets.js
node tools/verify/petskins.js
node tools/verify/compile.js
node tools/verify/localorder.js
bash tools/verify/suite.sh --quiet
```

`holiday-pets` should then say "0 of 12 still to build" (or the number you
left), and `halloween-power` "12 on their own". Fix `wiki/systems/pets.md`
(the twelve's bodies) and add a `wiki/log.md` entry. Commit only the new
module, the two regenerated files and those wiki files.

The report (`build/cursor/halloween-pet-bodies-report.md`) needs:
- a table of the twelve: built or left out, parts count, and what you fixed
  after the first look;
- the front and 3/4 captures, or where they are saved;
- a short "works but maybe ugly" list for the owner's taste call.
