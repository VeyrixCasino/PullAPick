# Ore faces — the hand-made set

30 pixel-art ores, drawn by hand, sliced out of `_source-sheet.png` (1448×1086,
a 6×5 grid) by `tools/slice-ore-sheet.js`. Uploaded 2026-09-28.

Each tile is trimmed to its own art, padded to a square so nothing stretches on
a block face, scaled to 64px nearest-neighbour so the pixels stay hard, and
written with the white ground knocked out to alpha.

## Moderation

A freshly uploaded image exists immediately — `GetProductInfo` resolves it —
but Roblox does not serve it for rendering until it clears moderation. Until
then a Decal or Texture pointing at it draws nothing, with no error.

Confirmed rather than assumed: a block with the built-in `rbxasset://textures/face.png`
drew its smiley in the same frame that two uploaded assets drew nothing, on the
same part type and the same code path.

## Re-uploading

`upload_image` takes http/https only, never local paths, and caps at 15 per
call. Serve the folder first:

```bash
node -e "const http=require('http'),fs=require('fs'),p=require('path');const d=process.cwd();http.createServer((q,r)=>{const f=p.join(d,q.url.replace(/^\/+/,''));if(!f.startsWith(d)||!fs.existsSync(f))return r.writeHead(404),r.end();r.writeHead(200,{'Content-Type':'image/png'});fs.createReadStream(f).pipe(r)}).listen(8733)"
```
