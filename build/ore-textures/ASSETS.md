## Re-uploading

`upload_image` takes http/https only, not local paths. Serve the folder and
pass localhost URLs:

```bash
node -e "const http=require('http'),fs=require('fs'),p=require('path');const d=process.cwd();http.createServer((q,r)=>{const f=p.join(d,q.url.replace(/^\/+/,''));if(!f.startsWith(d)||!fs.existsSync(f))return r.writeHead(404),r.end();r.writeHead(200,{'Content-Type':'image/png'});fs.createReadStream(f).pipe(r)}).listen(8731)"
```
